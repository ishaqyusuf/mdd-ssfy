# Define The Admin Approval Request Boundary

Type: grilling
Status: open
Blocked by: 03
Parent: [`../map.md`](../map.md)

## Question

Which blocker classes can generate a driver permission request, and what does
approval actually do for each class? Distinguish at least missing production
assignment, completed-but-unsubmitted production, pending material review,
open inbound work, missing inventory configuration, genuine physical shortage,
Special Order enforcement, and stale revisions. Define required admin
capabilities, review evidence, reason, expiry, idempotency, approve/deny
outcomes, and what must remain impossible to bypass.

The answer should reuse canonical receive/manual-fulfillment/production-review
or revision-bound override commands where applicable. A generic status rewrite
or blanket skip is not an acceptable resolution.
