# Define The Admin Command Center

Type: grilling
Status: open
Blocked by: 05, 06
Parent: [`../map.md`](../map.md)

## Question

What information architecture lets office admins oversee orders, assigned and
available drivers, outgoing activity, lifecycle status, packing progress,
approval requests, exceptions, and fulfillment without duplicating several
mini-apps? Define the primary sections, operational summaries, default table
columns, attention queues, detail-sheet tabs, driver activity view, filters,
bulk actions, and the single most important next action for each lifecycle
stage.

The answer should adapt the existing six-section Dispatch Admin workspace and
Sales Finance shell rather than assuming every current section survives
unchanged.
