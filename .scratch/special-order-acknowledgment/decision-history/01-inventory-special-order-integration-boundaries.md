# Inventory Special Order Integration Boundaries

Type: task
Status: open
Blocked by: None

## Question

Create a factual inventory of the current authoritative integration boundaries the Special Order specification must address: internal new Sales Order declaration/final save, Sales settings, direct order document emails and resends/reminders, public capability links, PDFs and cached documents, Sales Activity and notifications, and every purchasing, production, packing, dispatch, automated, or batch mutation that could continue an order operationally. Identify existing reusable patterns and bypass risks without choosing or implementing the final design.
