# Define The Canonical Square Refund State Machine

Type: grilling
Status: closed
Blocked by: 01, 02, 09
Parent: [`../map.md`](../map.md)

## Question

What canonical Square Refund aggregate, immutable request identity, provider
state machine, amount reservation rule, transition ownership, and terminal-state
semantics should replace the current low-level refund call while preserving
provider truth and safe retry behavior?

## Comments

> *This was generated by AI during Wayfinder issue commenting.*

**Proposed answer:** Introduce one immutable Square Refund aggregate containing
origin, canonical Square tender identity, currency, total, principal/C.C.C/tip
breakdown, frozen Sales Order allocations, reason, commercial-action reference,
actor evidence, and a persisted provider idempotency key.

Track provider and local application state separately:

- Provider: `NOT_SUBMITTED`, `PENDING`, `COMPLETED`, `FAILED`, or `REJECTED`.
- Local application: `RESERVED`, `AWAITING_ALLOCATION`, `READY_TO_APPLY`,
  `APPLYING`, `APPLIED`, or `APPLY_FAILED`.

Confirmation atomically creates the immutable intent and reserves its amount
before any network call. One worker submits it and always reuses the stored
idempotency key after timeouts or ambiguous responses. Webhooks and
reconciliation reads converge the provider state idempotently. Only provider
`COMPLETED` permits accounting application; `FAILED` and `REJECTED` release the
reservation. A completed/applied refund cannot be edited or deleted.

**Why:** This separates provider truth from local accounting and makes retries,
pending refunds, and failure recovery safe.

**Assumptions / risk:** Provider completion and local application can
temporarily diverge, so `COMPLETED + APPLY_FAILED` must be a prominent Finance
exception with automatic retry.

### Resolution

Implemented as proposed with separate durable provider/application states,
immutable cents-based intent/allocation evidence, pending reservations, one
persisted idempotency key, provider-first completion, and retryable local apply.
