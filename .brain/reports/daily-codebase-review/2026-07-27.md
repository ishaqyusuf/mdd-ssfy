## Worker Usability Review

Sales reps now have stronger Sales Overview production preflight and customer/address editing coverage, which helps catch customer/tax/door/PDF readiness before a door reaches production. The remaining usability problem is hidden trust: if data is available from public read routes, the UI may look role-aware while API calls are not consistently accountable.

Production, dispatch, warehouse, installers, and drivers benefit from the completed dispatch proof migration. The next usability gate is inventory correctness: workers need one clear answer for whether a line is ready, short, inbound, held, partially shippable, or blocked by mapping. Brain still records this as open.

Office/admin staff still lack a real active-session view and revoke action. In a shared workstation environment, this is a practical accountability gap: staff cannot verify stale sessions, unknown devices, or whether a permission change has taken effect.
